## mechta.kz — JSON API, браузер не нужен

Список товаров:

    GET https://www.mechta.kz/api/v3/catalog/products
        ?slug=<section-slug>&page=<N>&pageSize=<≤50>
        [&properties[discount][]=has_discount]
        [&orderBy=price&direction=asc]

Ответ: `{"products":[...], "meta":{"currentPage","totalPages","perPage","totalCount"}}`.
`pageSize` > 50 → 422 `validation.max.numeric`.

**Обязательные заголовки** (иначе Cloudflare 403 «Just a moment…» или 422 `device_id_not_provided`):

    User-Agent: <обычный Chrome UA>
    Accept: application/json, text/plain, */*
    Accept-Language: ru
    Referer: https://www.mechta.kz/
    Sec-Fetch-Site: same-origin
    Sec-Fetch-Mode: cors
    Sec-Fetch-Dest: empty
    X-Mechta-App: site
    X-Mechta-Device-Id: <любой uuid4, стабильный на обход>

Без `Sec-Fetch-*` Cloudflare отдаёт 403 даже на API. `x-city-code` не обязателен (по умолчанию Алматы).
Имена заголовков взяты из бандла `/_nuxt/Ad5JuF6P.js`, функция `sae()`.

Поля товара: `id` (uuid), `code`, `slug` (карточка: `https://www.mechta.kz/product/<slug>/`),
`name`, `prices.basePrice` (зачёркнутая), `prices.finalPrice` (текущая), `discount`,
`availability` ("available"…), `lowStock` («Осталось мало»), `onlyShopwindow` («На витрине»),
`preorder`, `metrics.brand`, `metrics.category`, `categories[]` (цепочка slug по уровням).

## evrika.com — Next.js SSR, данные в __NEXT_DATA__

- Категории: `https://evrika.com/catalog/<slug>/c<id>` (НЕ `/category/...` — отсюда 404 в старой разведке).
  Полный список (281 шт.): `sitemap.xml` → `sitemap_almaty.xml` → `sitemap_almaty_categories_0.xml`,
  либо query `categories/menutree` внутри `__NEXT_DATA__` (id, slug, parent_id).
- **Товары отдают только листовые категории.** Верхние (`smartfony-i-gadzhety/c171` и т.п.) — витрина без товаров.
- Пагинация: `?page=N`, 50 товаров на страницу. `meta: {current_page, last_page, per_page, total}`.
- Данные: `props.pageProps.dehydratedState.queries[]`, где `queryKey[0] == "products"` → `state.data.data[]`.
- JSON-роут без HTML: `https://evrika.com/_next/data/<buildId>/ru/catalog/almaty/<slug>/c/<id>.json?page=N`
  (buildId меняется при деплое — брать из `__NEXT_DATA__.buildId`; HTML-вариант устойчивее).
- **Медленно: 12–35 с на страницу** (и HTML, и _next/data). Нужна параллельность и/или редкий обход.
- Фильтра «скидка» нет. Скидка = `old_cost > cost` (в смарт-часах 31 из 50).
- `back.evrika.com/api/v1/*` → 401, не использовать.
- robots.txt сейчас: `?sort=`/`?f=` больше НЕ запрещены (в handoff устарело); запрещены `?city=`, cart/checkout и т.п.
  Город по умолчанию — Алматы (city_id=1).

Поля товара: `id`, `guid`, `slug` (карточка: `/catalog/<slug>/p<id>`), `vendor_code`, `name`,
`cost` (текущая), `old_cost` (зачёркнутая; = cost, если скидки нет), `stock`,
`availableForPurchase`, `availableForPurchaseFromDc`, `is_preorder`, `brand`, `category_id`, `category_name`, `badges`.

## Решения владельца (2026-09-13)

- mechta: обходить **все товары** 6 разделов (без фильтра has_discount) — нужна история до падения цены.
- evrika: листовые подкатегории разделов-аналогов (171, 71, 106, 244, 75), обход в несколько потоков.
- Хостинг: GitHub Actions; **первым шагом — пробный workflow**, проверяющий, пускает ли Cloudflare IP раннера.
- Транспорт: **Playwright** (решение владельца). Chromium проходит JS-челлендж Cloudflare; API mechta
  вызывается `fetch` из контекста открытой страницы раздела, evrika читается из `#__NEXT_DATA__`.
  Репозиторий: https://github.com/john88cool-coder/skidki-mechta-evrika

## Cloudflare распознаёт старый headless (смок 2026-09-13)

Старый headless Playwright (headless shell) с подменённым UA получал 200 только на ПЕРВЫЙ
запрос к API mechta, дальше — 403 «Just a moment» на всё, перезагрузка не помогала.
Выдавали: `navigator.webdriver = true`, бренд `HeadlessChrome` в Client Hints, UA Chrome/128
при движке 151. Эксперимент (12 запросов подряд):

| Вариант | Итог |
|---|---|
| старый headless + UA Chrome/128 | 200, затем 11 × 403 |
| `channel="chromium"` (новый headless) + родной UA без «Headless» + `--disable-blink-features=AutomationControlled` + webdriver скрыт | 12 × 200 |

Реализовано в `src/skidki/browser.py`. UA не придумывать — только чистить родной:
версия обязана совпадать с `sec-ch-ua`.
