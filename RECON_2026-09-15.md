# Разведка shop.kz, sulpak.kz, technodom.kz, alser.kz — 2026-09-15

Живая проверка (curl + Playwright-трейсы). Дополняет RECON_2026-09-13.md.
Все четыре сайта отдают контент обычному curl (IP дата-центров GitHub не
проверялся — обход всё равно идёт с домашнего ПК).

## technodom.kz — API katalog/api/v2, сортировка по скидке

Сайт Next.js, но SSR кладёт товары в разметку только на первой странице
категории (page=2+ SSR отдаёт пустой `productList`), поэтому берём API напрямую:

    GET https://api.technodom.kz/katalog/api/v2/products/category/<slug>
        ?city_id=5f5f1e3b4c8a49e692fefd70&limit=50&page=N
        &sorting=discount:desc

- Ветка целиком: по верхнему узлу отдаёт все товары подкатегорий
  (`smartfony-i-gadzhety` → 1 656, `noutbuki-i-komp-jutery` → 2 224 и т.д.).
- `sorting=discount:desc` — легальная сортировка API (иначе 400 с подсказкой
  «created_at|price|rating|score|discount»); скидочные идут первыми.
- Ответ: `{payload: [...], total, page, limit}`. Товар: `sku`, `title`,
  `price`, `old_price`, `discount`, `uri` (карточка `/product/<uri>`),
  `brand`, `categories_ru`. Наличие в API не выражено — считаем в наличии.
- Вне браузера api.technodom.kz отвечает 404 на /katalog/... — сначала заходят
  на страницу сайта (cookies Cloudflare), дальше запросы из контекста.
- Категории: categories-server-sitemap.xml (490 URL), но для обхода нужны
  только 6 корней.
- Объём 2026-09-15: ~9 200 позиций в 6 корнях, 1 919 со скидкой.

## shop.kz — Битрикс, SSR-листинги

- Раздел: `/offers/<slug>/`, пагинация `?PAGEN_1=N`, 28 карточек на страницу
  (SIZEN_1 игнорируется). Выход за пределы — HTTP 200 и пустой листинг.
- Число страниц: на странице 1 в пагинации есть ссылка на последнюю
  (`PAGEN_1=<max>`; Битрикс рисует первые + последнюю).
- Карточка в HTML:
  - `data-product='{JSON}'` — `product_id`, `item_name`, `item_brand`,
    `item_category`, `price`, `dimension3` («available»/«not available»);
  - `<link itemprop="url" href="/offer/<slug>/"` — ссылка карточки;
  - `<div class="old_price"><span>729 990 ₸</span>` — зачёркнутая «цена по прайсу»;
  - `<div class="current_price"><span>699 990 ₸</span>` — цена интернет-магазина.
- Категории: sitemap-iblock-*.xml (125 файлов) — там и секции, и товары
  (/offer/...). Секции отбираются префиксом /offers/.
- Обходить только аналоги разделов mechta (38 секций, ~11 800 позиций,
  2 487 со скидкой 2026-09-15).
- Часть секций из старых сайтмапов 301 на /catalog/ (multivarki-parovarky,
  kuhonnye-kombayny-i-mashiny на 2026-09-15) — пустая первая страница.

## sulpak.kz — SSR + AJAX /Filter/LoadProducts

- Категория: `/f/<className>` (без города — иначе часть категорий 404/301).
  Первая страница приходит SSR: 22 карточки (`onPage=22`).
- Страницы 2+:

      GET /Filter/LoadProducts?className=<cat>&selectedPropertiesTokens=~
          &selectedActionsTokens=~&sort=PopularityDesc&listing=default
          &onPage=22&page=N&price=~
          X-Requested-With: XMLHttpRequest

  Ответ — JSON: `products` (HTML-блоки карточек, каждый блок продублирован
  дважды — список + плитка, нужен дедуп) и `paginator` (там `data-pagesCount`
  — сразу всё число страниц; SSR-пагинация показывает только первые три).
- Карточка: `data-code`, `data-name`, `data-price`, `data-brand`,
  ссылка `/g/<slug>`; зачёркнутая цена — `div.product__item-price-old`,
  процент — `div.product__label-discount`; «На витрине» и «Нет в наличии» —
  текстовые метки внутри блока.
- Меню каталога: POST/GET `/Home/GetMainMenuView` (JSON-строка с HTML,
  ~550 ссылок /f/...).
- Сортировок по скидке нет (noveltydesc | price | pricedesc | popularitydesc).
- Эпизодические 404 на отдельные категории — лечатся ретраями с паузой.
- Категории-аналоги mechta: 49 классов (config.SULPAK_CATEGORIES),
  ~3 700 позиций 2026-09-15.

## alser.kz — POST mobapi-v3-get-catalog

- Nuxt; SSR кладёт только 8 витринных карточек. Полный листинг — POST:

      POST https://alser.kz/api/v2/mobapi-v3-get-catalog
      Content-Type: application/json
      {"c_keyword": "<категория>", "page": N, "limit": 50,
       "location_id": 8, "only_local": false}

  Ответ: `data.products[]` (id, sku, title, keyword, price, price_old, brand,
  stocks_quantity, non_showcase, link_url) + `data.pagination`
  {page, perPage, total, pageCount, hasNext}.
- Категории: сайтмап https://alser.kz/uploads/sitemap/categories/root-categories.xml
  → /c/<keyword>/ (170 ключей без /f/... на 2026-09-15). В robots.txt sitemap
  объявлен: https://alser.kz/uploads/sitemap/index.xml.
- Вне браузера POST отдаёт 404 — сначала страница сайта ради cookies.
- Группы — по подстрокам keyword (config.ALSER_GROUPS, часть ключей казахские).
- Объём 2026-09-15: ~890 позиций, 130 со скидкой. ~15% категорий — услуги/ПО,
  уходят в «Прочее».
