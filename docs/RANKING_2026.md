# «Лучший товар» — метрика выбора · 2026-09

> Как ИС определяет, что товар — *лучшая покупка*, а не просто «самая большая цифра на ценнике».

## Принцип

Магазинная зачёркнутая цена — ненадёжна: её рисуют. ИС считает три независимые оценки и сводит в **Value Score (0–100)**.

### 1) Честная скидка — `fair_discount`

- История ИС (медиана 14 дней, взвешенная по отрезкам, минимум 3 дня) — уже есть в `evaluate.py`.
- **Дополнение:** медиана цены на маркетплейсах (`kaspi`/`wildberries`/`ozon`) по той же модели (нормализация названия → кластер). Если зачёркнутая цена сильно выше медианы маркетплейса — это сигнал рисованности, `fair_discount` режется.
- Формула: `fair = price_vs_median_own` + `price_vs_marketplace_median`, берём минимум из двух (консервативно).

### 2) Ценность — `value_score`

```
value = w1*fair_discount_norm + w2*brand_trust + w3*availability + w4*freshness
```

- `fair_discount_norm` — `fair_discount` → 0..1 (0%→0, 20%→0.5, 40%+→1.0, клип 0..1).
- `brand_trust` — белый список брендов из продаж KZ (эвристика: Samsung/Apple/Xiaomi/LG и т.д. выше, noname ниже). 0..1.
- `availability` — в наличии =1, «на витрине»/«мало» =0.6.
- `freshness` — давность обхода: свежий (≤6ч)=1, 6–24ч→0.5, >24ч→0.2.

Веса по умолчанию `w = (0.55, 0.2, 0.15, 0.10)`, сумма 1. Масштабируем в 0..100.

### 3) Внешние оценки — `external`

- Источники: отзывы/рейтинги маркетплейса (Kaspi/WB/Ozon), если доступны на карточке; независимые обзоры (условно — `rating` из API, где есть).
- Хранится как `rating` (0..5) + `reviews_count` + `source_url`. В скоринг входит как мягкий бонус: `+5` к score если `rating≥4.5` и `reviews≥50`, иначе `+0`.

## Бейджи в UI

| Бейдж | Условие |
|-------|---------|
| **Выбор ИС** | `value_score ≥ 78` и `fair_discount ≥ 18%` и `price ≥ 20 000 ₸` |
| **Честная скидка** | `fair_discount ≥ 15%` (подтверждена историей ≥3 дн) |
| **Топ-Бренд** | бренд в топ-списке категории |
| **Рисованная?** | `shop_discount − fair_discount ≥ 15 п.п.` — предупреждение |

## Где живут данные

- `Product` → поля `rating`, `reviews_count`, `market_median` (опционально,nullable).
- `export.py` → считает `value_score`, `fair_discount`, `is_pick` при экспорте `latest.json`.
- `evaluate.py` → правило «честной скидки» использует медиану маркетплейса, если доступна.
- Фронт читает готовый `value_score` и рисует бейджи без пересчёта.

## Ограничения

- Маркетплейсная медиана — только когда товар нашёлся кластеризацией названия; иначе падает на историю ИС.
- Внешние оценки — справочны, не решают исход; товары без оценок не штрафуются.
- «Рисованная?» — эвристика, не ярлык мошенника, а сигнал присмотреться к истории цены.
