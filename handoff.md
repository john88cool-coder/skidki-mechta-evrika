## 2. Прокси-разведка (для mechta в облаке)

- toranproxy.com — НЕ прокси-сервис (устаревший PHP-инструмент), вычеркнут.
- **Decodo (ex-Smartproxy), бесплатный план владельца**: 1 ГБ/мес, дата-
  центровые IP (dc.decodo.com, порты 10001–10010, user `sptighsmpv`, пароль —
  в панели Decodo → Free Proxies → Proxy setup). Живая проверка 2026-09-18:
  все 10 IP дают mechta 403 «Just a moment…» (Playwright, полный анти-детект);
  остальные 5 магазинов через эти IP — 200. Вывод: дата-центровый класс
  Cloudflare на mechta режет целиком; для mechta нужны только резидентные IP.
- Оценка трафика: полный обход mechta ≈ 15 МБ → ~5 ГБ/мес при обходе раз в
  2 ч. Decodo residential с KZ-эндпоинтом (`kz.decodo.com`, sticky 40001–49999):
  $3.75/ГБ (3 ГБ, $11.25/мес) — впритык, 10 ГБ $35/мес — комфорт. Есть
  резидентный триал 3 дня/100 МБ — достаточно на ~7 обходов для проверки.
- Решение владельца: **гибрид без затрат** (см. §3). Резидентный прокси —
  опция на потом.

## 3. Гибрид (в работе, НЕ закоммичено)

сводки шлют все группы (их база в кэше Actions не связана с ноутбуком).

## 4. Черновик INSTALL-LAPTOP.md (суть для ноутбука)

1. Распаковать пакет, поставить Python 3.12+ (галочка PATH).
2. `pip install -e ".[dev]"`; `python -m playwright install chromium`.
3. `.env`: TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID (те же, что в облаке —
   слушатель на ноутбуке будет обслуживать кнопки этого бота).
4. Положить фильтрованную базу в `data/skidki.sqlite3` (в пакете).
5. `powershell -ExecutionPolicy Bypass -File deploy\install_task.ps1 -Shops mechta`
   — обход mechta каждые 2 ч (в :17), скрыто, будит ноутбук из сна
   (в плане питания разрешить таймеры пробуждения).
6. `deploy\install_bot_task.ps1` — слушатель кнопок/команд.
7. Проверка: `skidki crawl --console --shop mechta`, логи `logs\crawl-*.log`.
8. Ноутбук должен быть включён/спать с разрешёнными wake timers; пропущенный
   запуск выполнится при первой возможности.

## 5. Факты, которые надо не потерять

- Прод-база домашнего ПК: `data/skidki.sqlite3` (~5.2 МБ; mechta 24 обхода,
  evrika 24; новые 4 магазина в проде ещё не обходились — их история начнётся

  находок не будет — это норма.
- Один токен бота = один getUpdates-слушатель; слушатель живёт на ноутбуке.
- Decodo free: 1 ГБ/мес, расход тестами ~несколько МБ; креденшелы в панели.
- Прокси-скрипт проверки портов: см. историю — Playwright + `proxy={server,
  username, password}`; для резидентного триала повторить с
  `http://kz.decodo.com:<sticky-порт>`.
